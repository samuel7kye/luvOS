# luvOS 1.0

Abra `index.html` no navegador. O player DVD fica no centro da tela e acompanha a navegação pelo álbum. A bio no fim da página leva aos perfis de Samuel e Kailayni.
As janelinhas mudam de posição a cada abertura do álbum. Arraste para reorganizar ou clique numa foto para ampliar.

## Ajustar o álbum

- Em `historia.js`, a lista `fotos` de cada capítulo usa os nomes dos arquivos da pasta `images`. A primeira foto vira a capa e as demais aparecem quando ela é aberta.
- `Eu.png` e as cinco primeiras entradas de `fotosSoltas` aparecem nas janelinhas espalhadas pela página. Cada entrada usa os campos `arquivo` e `nome`.
- Coloque os áudios na pasta `musicas` e liste-os em `historia.js` na ordem de reprodução. Cada faixa usa os campos `arquivo`, `titulo` e `artista`.
